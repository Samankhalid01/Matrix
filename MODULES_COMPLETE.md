## 📚 API Quick Reference

### Notifications
```javascript
GET  /api/notifications?recipient_type=admin&is_read=false
POST /api/notifications { title, message, priority }
PUT  /api/notifications { notificationIds: ['id'] }
DELETE /api/notifications?id=xxx
```

### Promotions
```javascript
GET  /api/promotions?is_active=true
POST /api/promotions { name, discount_type, discount_value }
POST /api/promotions/calculate-discount { customerId, cartTotal, promoCode }
PUT  /api/promotions { id, ...fields }
```

### Analytics
```javascript
GET /api/analytics/performance?period=monthly
GET /api/analytics/customer-segments
GET /api/analytics/forecast?product_id=xxx&days=30
```
